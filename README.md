# 跳过广告 · AdSkipper

免 root 的安卓去广告工具，专门为 **三星 S24+ / One UI 8.5 / Android 16** 调的。

两层机制，都在本机跑，不联网、不上传任何数据：

| 层 | 技术 | 干什么 | 省电 |
|---|---|---|---|
| ① 无障碍自动点击 | `AccessibilityService` | 读到「跳过 / 跳过 5s / 关闭」就点一下，干掉开屏广告和应用内弹窗 | 事件驱动，只在窗口出现时干活，之后彻底闲着 |
| ② 本地 DNS 拦截 | `VpnService` + 本地 DNS 代理 | 只把 DNS 查询接下来，命中广告域名就回 NXDOMAIN，广告资源加载失败 | 只碰 DNS 包，不代理网页流量 |
| ③ 通知清理（可选） | `NotificationListenerService` | 清掉你指定包名的广告推送 | 事件回调，零轮询 |

---

## 先说清楚：能跳什么、跳不了什么

**能跳（效果好）**
- 开屏广告：主流 App 里带「跳过 / 跳过 5s」原生按钮的，绝大部分能自动跳过
- 应用内插屏、弹窗、"以后再说 / 残忍离开 / 我知道了"
- 广告推送通知（要手动填包名）

**跳不了（物理上做不到，别指望）**
- 信息流 / 原生广告（微博、淘宝、抖音、知乎里混在内容里的）
- 游戏内广告（Unity Ads、AppLovin 这类引擎自绘的），只能靠 DNS 层让它加载失败
- 视频贴片广告（爱奇艺、腾讯视频、优酷、YouTube）
- 用 Canvas / Flutter / SurfaceView 自绘、无障碍树里根本没有文字节点的广告（这种「跳过」按钮在系统眼里不存在）

**能做到多少**：日均最烦人的开屏广告，实测同类工具能干掉 70~85%，看具体 App。**"清掉所有广告"的 App 不存在。**

# 第一步：拿到 APK（不用装 Android Studio）

你电脑上没有 Android 编译环境，所以用 GitHub 的免费云构建。整个流程只需要浏览器，大概 10 分钟。

### 1. 注册 / 登录 GitHub
打开 https://github.com ，有账号直接登录，没有就注册（免费）。

### 2. 建一个仓库
- 右上角 `+` → **New repository**
- Repository name 填 `AdSkipper`
- 选 **Private**（私有，别人看不到）或 Public 都行
- **不要**勾 "Add a README file"
- 点 **Create repository**

### 3. 上传源码
- 把本目录（`AdSkipper` 文件夹）里的这些东西，**全部**拖进浏览器的上传框：
  `app` 文件夹、`settings.gradle.kts`、`build.gradle.kts`、`gradle.properties`、`README.md`、`.gitignore`
- 页面提示 "uploading your files" 后点 **Commit changes**

### 4. 单独创建构建脚本（关键一步）
浏览器的拖拽上传会**忽略以 `.` 开头的隐藏目录**，所以 `.github` 必须手动建：

- 仓库页点 **Add file** → **Create new file**
- 文件名输入：`.github/workflows/build.yml`
- 用记事本打开本地的 `.github/workflows/build.yml`，**全选复制**，粘贴到网页编辑框
- 点 **Commit changes**

### 5. 跑构建
- 点仓库顶部的 **Actions** 标签
- 左边点 **Build APK** → 右边 **Run workflow** → 绿色 **Run workflow**
- 等 2~4 分钟，列表里出现绿色 ✓

### 6. 下载 APK
- 点进那次绿色 ✓ 的运行记录
- 拉到页面最底部 **Artifacts** 区域 → 下载 **AdSkipper-apk.zip**
- 解压，里面就是 `app-debug.apk`（约 1~2 MB）

> 以后我改了代码，你重新上传/替换文件，再跑一次 Actions 就行。
> 工作流里缓存了签名文件，所以**新版本可以直接覆盖安装、不会丢设置**。

**Plan B（GitHub 上不去的时候）**
- 找一个装了 Android Studio 的朋友：`File → Open` 选这个文件夹，点 Run 就能出 APK；
- 或者把这堆文件给手机维修店/会安卓开发的人，同样的操作用 5 分钟。

# 第二步：装到手机上（三星 S24+ / One UI 8.5 专属）

### 1. 先关掉「自动拦截器」
One UI 6.1 以后默认拦截侧载安装的 App。

`设置 → 安全与隐私 → 自动拦截器` → 关掉（装完可以再打开）

### 2. 安装 APK
把 `app-debug.apk` 传到手机（微信文件传输助手 / USB / 网盘），点开安装。
提示"未知来源应用"时允许一次即可。

### 3. 允许「受限设置」（Android 14+ 必须，否则开不了无障碍）
`设置 → 应用 → 跳过广告 → 右上角 ⋮ → 允许受限设置`

侧载 App 的无障碍、通知使用权默认是被系统锁住的，不点这个开关，后面两步永远开不起来。

### 4. 开无障碍服务
App 里点 **① 去开启「无障碍服务」**，或者手动：
`设置 → 辅助功能 → 已安装的服务 → 跳过广告 → 打开`

打开时系统会弹「此服务可以查看屏幕内容」的警告，确认即可。

### 5.（可选）DNS 拦截层
App 里打开 **「开启 DNS 拦截」**，系统会弹 VPN 授权，同意。

先做两件事，否则它不生效：
- `设置 → 连接 → 更多连接设置 → 私人 DNS` → 改成 **关闭**
  （私人 DNS 会走 DoT 绕过 VPN 的 DNS，开着它 DNS 拦截就是废的）
- 确认没有别的 VPN / 代理 / 梯子在跑（安卓同一时间只允许一个 VPN）
- 开完点 App 里的 **「查看 DNS 拦截统计」**，确认一次（很重要，见下文）

### 6.（可选）通知清理
- App 里打开「启用通知清理」，点 **② 打开「通知使用权」设置**，允许
- 在输入框里填要清理的包名，逗号隔开，比如：
  `com.xingin.xhs,com.taobao.taobao`
- 点「保存通知清理名单」

# 第三步：省电设置（重要，不做会被后台杀掉）

按顺序做这三项：

1. **加进「永不休眠的应用」**
   `设置 → 电池 → 后台使用限制 → 休眠应用` → 找到「跳过广告」→ 改为 **永不休眠**
2. **关掉「移除权限节省空间」**
   `设置 → 应用 → 跳过广告 → ⋮ → 管理空间/权限` → 关掉「不使用时移除权限」
3. **App 里点「忽略电池优化」** → 允许

无障碍服务本身是系统托管的，正常不会被杀；这三项主要是防冗长的后台清理。

**实际耗电**：正常情况下可以忽略（< 1%/天级别）。判断依据：它不轮询、不唤醒、不持有 wake lock，只有别的 App 切窗口时才被系统叫起来干几十毫秒的活。

> 如果你开了 DNS 层，它会常驻一个前台通知（VPN 图标）。那是系统要求，不能去掉。

# 怎么调规则（这就是为什么它不完美但能变好）

### 看日志
App 里点 **「查看日志」**：

```
12:31:02 [CLICK] com.taobao.taobao  跳过文字 跳过 5s  score=112
12:31:05 [MISS]  com.xxx.app  跳过文字 跳过  找到了但点不动
12:31:20 [RULE]  规则已加载 v1：跳过 8 条，关闭 16 条
```

- `[CLICK]` = 跳过成功
- `[MISS]` = 找到了按钮但点不动（这种要发我，我加手势兜底规则）
- 没有日志 = 那个 App 的广告按钮在无障碍树里根本不存在（自绘广告，无解）

### 上次扫描结果
打开一个有开屏广告的 App，等广告出来，再切回本 App 点 **「上次扫描结果」**。它会告诉你：上一次对其他 App 的扫描看了多少控件、有没有命中、命中在哪个控件上。

- 显示「命中【跳过 xxx】」但还是没跳过 → 点不动，把日志发我
- 显示「扫描 N 个节点，没找到…」→ 那个 App 的广告按钮系统读不到（自绘广告），无解

（说明：不能在广告显示时"现场检测"，因为一切回本 App，广告页就已经不在前台了。所以这里看的是"上次扫描"的记录。）

### 自己加规则
改 `app/src/main/assets/rules.json`：

```json
{
  "skipPatterns": ["^跳过"],                  // 高置信度：文字是「跳过」类，任何时候都点
  "closePatterns": ["^关闭广告$"],             // 中置信度：只在 App 刚进前台 12 秒内点，且必须可点
  "aggressiveClosePatterns": ["^关闭$", "^×$"],// 低置信度：只有开了「激进模式」才点
  "skipIds": ["btn_skip"],                    // 控件 id 里包含这些字符串就点
  "apps": {                                    // 给单个 App 加专属规则
    "com.example.app": { "skipPatterns": ["^跳过广告"] }
  },
  "launchWindowMs": 12000                      // 「关闭类」的安全时间窗（毫秒）
}
```

改完重新上传、重新跑 Actions、覆盖安装。

### 激进模式（默认关）
主界面有个「激进模式」开关。关着时只点高置信度的广告关闭按钮（`关闭广告 / 残忍离开 / 以后再说 / 直接进入`）；打开后会额外点 `关闭 / × / 我知道了 / 不感兴趣` 这类通用按钮。

**建议**：先用默认的关着，发现哪个 App 的弹窗关不掉，再打开激进模式试。开着它误点概率明显上升（比如把某个正常的确认弹窗关掉），这也是为什么它默认关闭、并且黑名单要认真填。

### 加黑名单（防误点）
主界面底部「不处理的应用」填包名，逗号隔开。**银行、支付、证券类强烈建议加进去**：这类 App 里有大量"关闭""确认"，宁可让它弹广告，也别让工具乱点。

# DNS 层的取舍（自己决定开不开）

**先说风险**：这一层用的是「只路由 DNS 的 VPN」（不抓全流量），靠系统把 DNS 查询优先送给 VPN 的 DNS 服务器来实现拦截。这是 DNS66 / personalDNSfilter 那类工具的路子，在多数机型上成立，但**在个别 ROM / 系统版本上可能完全不生效**，而且我这边没有真机可以替你验证。

所以：**开完用几分钟手机，再点 App 里的「查看 DNS 拦截统计」**。它显示的是 tun 里真实收到/拦截了多少条 DNS 查询——这是唯一可靠的判据（不能用"在本机 ping 一下域名"来测，因为本 App 自己被排除在 VPN 之外，测得不准）。

- 「收到查询」是 0 → 这层在你机器上没打通，**直接关掉 DNS 开关**，只用无障碍层；
- 收到几百条、命中几条 → 正常工作；
- 想重新观察就先点「清零重计」，刷几个 App 再回来看。

**好处**：能从源头减少一批 banner / 插屏 / 激励视频的广告资源，顺带减少跟踪统计。

**代价**：
1. 占用系统 VPN 通道 → **和公司内网 VPN、代理工具冲突**，二选一；
2. `私人 DNS` 必须**关闭**（不能是"自动"，DoT 会绕过 VPN）；
3. 黑名单里某个域名可能同时被正常功能使用 → 表现为某 App 图片加载不出、分享失败、推送延迟。**出现这种情况先关掉 DNS 层**，然后从 `blocklist.txt` 里把可疑域名注释掉；
4. 广告 SDK 加载失败时，有的 App 会弹"网络连接失败"或白屏一会儿，属正常；
5. 首次启动时如果反复拨开关，可能看到 VPN 图标闪一下——正常。

**如果你只想用①层**，DNS 层完全不用开，跳开屏广告照样工作。

# 常见问题

**Q: 开了无障碍，但某个 App 广告完全没反应？**
A: 绝大多数是自绘广告（Flutter / 游戏引擎 / Canvas），系统读不到按钮。这种只能靠 DNS 层让它加载不出来。用「上次扫描结果」确认一下，如果显示"没找到可点的跳过/关闭按钮"，就是这种。

**Q: DNS 统计显示「收到查询 0 条」怎么办？**
A: 说明「只路由 DNS 的 VPN」这个套路在你的机器 / 系统版本上没打通（这是个真实存在的兼容性风险，我这边没有真机替你验证）。处理办法：直接把 DNS 开关关掉，只用无障碍层，跳开屏广告照样工作。别为了一个没生效的功能白占 VPN 通道。

**Q: 会不会误点到别的东西？**
A: 设计上有多重保护：只匹配「跳过/关闭」这类短文字（≤24 字）、只点窗口出现后 12 秒内的关闭类、避开系统界面/输入法/桌面/本 App、避开全屏容器、每个窗口最多点 12 次、两次点击间隔 ≥320ms。但**任何自动点击工具都有极小概率误点**，所以黑名单功能建议认真用。

**Q: 会不会耗电/卡顿？**
A: 不会。没有轮询、没有常驻线程池、没有 wake lock。扫描放在独立后台线程，且每个窗口只在前 25 秒内响应内容变化事件。相比常驻的广告 SDK，它省的电可以忽略。

**Q: 会不会有隐私问题？**
A: 工程里没有 `INTERNET` 之外的可疑权限，代码自己读一遍就知道：它只把当前屏幕的按钮文字读出来做正则匹配，日志只存在内存里（最多 400 条，重启就没）。DNS 层只解析域名、只转发，不记录、不上报。

**Q: 为什么不做 root 版？**
A: 因为 S24+ 解锁 bootloader 会**永久熔断 Knox（eFuse）**：Samsung Pay / 钱包、Secure Folder、Samsung Pass、多数银行 App 直接报废，保修也没了。为了拦信息流广告付这个代价不值。root 版能做到更多（hook 广告 SDK 直接返回"无广告"），但那是给备用机玩的。

**Q: 升级新版本要卸载吗？**
A: 不用，工作流缓存了签名。万一缓存被 GitHub 清掉了导致签名变了，安装时会报"应用未安装"，卸载旧版重装即可（设置会丢）。

# 工程结构

```
AdSkipper/
├─ .github/workflows/build.yml      # 云构建
├─ settings.gradle.kts / build.gradle.kts / gradle.properties
└─ app/
   ├─ build.gradle.kts              # 零第三方依赖，只有 AGP + Kotlin 插件
   └─ src/main/
      ├─ AndroidManifest.xml
      ├─ assets/rules.json          # 文字/控件 id 匹配规则
      ├─ assets/blocklist.txt       # 广告域名黑名单
      ├─ res/xml/accessibility_service_config.xml
      ├─ res/values/strings.xml
      └─ java/com/adskip/app/
         ├─ AdSkipService.kt        # ★ 核心：无障碍读屏 + 打分 + 点击
         ├─ RuleEngine.kt           # 规则解析与匹配
         ├─ AdDnsVpnService.kt      # VPN 容器
         ├─ DnsProxy.kt             # 极简 DNS 代理（NXDOMAIN 拦截）
         ├─ DnsStats.kt             # DNS 收到/拦截计数（判断这层到底通没通）
         ├─ Blocklist.kt            # 域名黑名单
         ├─ NotiCleanService.kt     # 通知清理
         ├─ MainActivity.kt         # 界面
         ├─ Prefs.kt / LogStore.kt / App.kt
```
